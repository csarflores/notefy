La idea

Un administrador multiproyecto
con alma de producto Apple.

Harold es una herramienta gratuita de gestión de tareas y notas. Organiza múltiples proyectos de forma independiente, colabora con tu equipo sin límites y disfruta de una experiencia fluida de alta gama — sin pagar un centavo.

Editor enriquecido

Texto con formato tipo Word: encabezados, listas, código con syntax highlighting, imágenes y enlaces — powered by TipTap.

Tres niveles de privacidad

Privadas solo para ti, compartidas con permisos de edición, o ligadas a un proyecto para mantener el contexto junto al trabajo.

Exportación libre

Cada nota se exporta a Markdown (.md) o se imprime como PDF con un clic. Tu contenido nunca queda atrapado.
